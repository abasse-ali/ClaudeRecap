# Exemples

> Source : https://code.claude.com/docs/en/agent-sdk/examples · [← Index](../31-index-documentation-officielle.md)

*Trouver un projet Agent SDK complet et exécutable, ou une recette guidée du Claude Cookbook, correspondant à ce que vous voulez construire.*

Cette page vous oriente vers des projets Agent SDK complets et exécutables, ainsi que vers des recettes guidées du Claude Cookbook. Les applications se trouvent dans le dépôt [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos), et les recettes Python dans le [Claude Cookbook](https://platform.claude.com/cookbook).

---

## Commencer par un agent minimal

Si vous n'avez encore rien construit avec le SDK, commencez par l'une de ces ressources avant de vous lancer dans une application complète :

- [Démarrage rapide de l'Agent SDK](https://code.claude.com/docs/en/agent-sdk/quickstart) : construisez votre premier agent fonctionnel en TypeScript ou en Python, étapes d'installation comprises. L'agent trouve et corrige des bugs dans un fichier d'exemple.
- [Hello World](https://github.com/anthropics/claude-agent-sdk-demos/tree/main/hello-world) : un projet TypeScript minimal à cloner lorsque vous voulez partir du code d'un dépôt.

## Explorer une application de démonstration

Les applications du dépôt [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos) sont des démos destinées au développement local, allant d'un client de messagerie (e-mail) à un système de recherche multi-agents. Clonez la démo dont la structure correspond à ce que vous construisez.

## Suivre une recette Python

La série Agent SDK du Claude Cookbook est une suite de recettes, chacune sous forme de notebook Python, qui progresse d'un simple agent de recherche jusqu'à des systèmes multi-agents sophistiqués. Chaque notebook s'appuie sur le précédent et introduit de nouveaux concepts et de nouvelles capacités. Commencez par [l'agent de recherche en une ligne (the one-liner research agent)](https://platform.claude.com/cookbook/claude-agent-sdk-00-the-one-liner-research-agent) et avancez dans l'ordre.

Pour des recettes couvrant l'ensemble des produits Claude, consultez le [Claude Cookbook](https://platform.claude.com/cookbook) complet.
